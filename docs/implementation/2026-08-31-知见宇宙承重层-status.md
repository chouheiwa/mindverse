## Task 1–8 已实现事实

1. **内容真相源。** 内容身份、`created | collected` 用户绑定、公开发现来源以及 `publishedAt / updatedAt / observedAt` 分离存储。公开搜索不会生成个人绑定，编辑时间不会冒充首发或收藏时间。解决不了的身份冲突被隔离，不合成问题。
2. **稳定宇宙实体。** 当前抽取概念全部是私有恒星，ID 由 scope 与规范化概念稳定计算。只有真实问题 ID、非空标题和规范知乎 URL 都可验证时才生成全局问题行星；回答卫星与文章探测器按稳定内容 ID 去重。作者门槛只接受可验证的稳定作者 ID。
3. **快照与分享后端。** 新快照携带 schema/analysis 版本，旧快照只读兼容，不从旧 Evidence 推导公开问题。后端提供 `POST /api/share/preview`、`POST /api/share`、`GET /api/share/{id}` 和所有者限定的 `DELETE /api/share/{id}`。创建必须携带与当前会话、选择和精确预览绑定的 digest。分享持久化保留所有权索引，支持重启后撤销与会话清除级联删除。
4. **前端严格契约。** Go 金文件覆盖公开字段，前端在 API 边界拒绝未知字段、访问器、稀疏数组、原型污染、超限图和过深嵌套，再生成冻结的域索引。旧契约不会合成新问题。
5. **3D 问题行星。** Three.js 场景只为准入后的真实问题生成行星，问题卡显示规范原页链接、回答数和可证明的个人关系。画布拾取之外还有语义化问题航道，支持键盘、焦点恢复、移动端单一导航和 reduced motion。WebGL 在私人数据到达后延迟加载。
6. **三模式工作台。** 个人轨道只接受真实创作/收藏绑定。“答案纪年”当前是存活答案的扁平回溯：至少 12 篇有真实首发时间的答案、3 个稳定作者、跨 3 个 UTC 日历年才展示；否则只显示实际阈值和原文。它不声称当年观点或社区份额。“观点棱镜”当前始终 `abstained`、`claims=[]`，明示证据不足。
7. **恒星详情与文章。** 恒星面板分开展示问题行星和“文章探测器 · 旁轨材料”，公开发现只标为公开发现，不冒充个人关系。长列表分批读取并恢复焦点。当前探测器是二维详情入口，还不是可操作的近景 3D 模型。
8. **显式分享前端。** 选择初始为空，候选问题和预览内容均分批渲染。变更选择会立即使旧预览失效；只有服务端预览成功且选择未改变时才能创建。`/s/{id}` 使用独立公开组件和严格 `ShareView` 解析器，不复用私人 Universe、Panel 或个人工作台。

## 公开字段与隐私边界

`ShareView` 只允许问题的 ID、标题、规范 URL、公开回答引用，以及回答的稳定 ID、所属问题、标题、规范 URL、经验证作者、首发/更新时间和公开计数。不导出：

- 私有概念恒星、星群和个人图结构；
- `created | collected` 绑定、收藏夹、采集时间和个人摘要；
- 公开发现路径和文章探测器；
- OAuth token 或会话标识。

公开 GET 路由不创建私有会话的服务端路由处理；前端请求也显式使用 `credentials: 'omit'`。`data/snapshots/*.json` 是服务端可撤销的公开分享快照，`.sessions` 只记录实际拥有公开分享的 owner 撤销证明；匿名或普通私有 GET 不会促发该文件写入。缺失、损坏或旧版 owner 索引会导致无法证明撤销权的旧公开分享被隔离并返回 404。运行时路径被 `.gitignore` 排除；私人认知快照尚未接入 HTTP 链路。

## API 行为摘要

| 端点 | 会话 | 当前行为 |
|---|---|---|
| `GET /api/oauth/status` | 需要 | 报告 OAuth 配置/登录状态，不伪装本地回调可用 |
| `POST/GET /api/universe` | 需要 | 启动生成/读取当前会话的宇宙 |
| `POST /api/share/preview` | 需要 | 从所选问题构建白名单视图与 consent digest |
| `POST /api/share` | 需要 | 重建视图并校验 digest 后创建 |
| `GET /api/share/{id}` | 不需要 | 只返回公开 `ShareView` |
| `DELETE /api/share/{id}` | 需要 | 仅所有者可撤销；非所有者与不存在统一为 404 |
| `DELETE /api/session/data` | 需要 | 取消进行中操作、清除内存凭证并级联撤销所有分享 |

## 明确未实现的产品方向

- **真正观点棱镜：** 还没有版本化 `PublicClaim`、主张抽取、论据支持/反驳关系或可审核的观点推断。
- **历史共识与地层：** 当前只有存活答案按首发时间的回溯，没有历史快照、当年可见集、修订轨迹或社区份额。
- **文章公开分享：** 文章探测器当前只留在私人恒星详情，不进入 `ShareView`。
- **探测器近景 3D：** 当前没有文章探测器的独立 3D 模型、拾取或近景交互。
- **OAuth 实际部署：** 代码已有 OAuth 流程和真实数据 Provider，但是否能完成登录取决于有效的 App ID/App Key/Access Secret、知乎开放平台配置和公网 HTTPS 回调。
- **长期账户与跨设备管理：** 当前所有权依赖服务器会话，不是长期账户系统。页面刷新后也没有分享管理列表，创建后需保存链接。
