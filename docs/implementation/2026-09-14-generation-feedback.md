# 生成进展与命名并发

生成页沿用原有星尘动画，新增私有会话的实际进展：读取条数与收藏夹完成数、
待分析条数与处理数、历史分析复用数、未获得有效标注的条数、星群命名完成数。
首次轮询立即显示服务端当前状态，刷新页面后已用时间沿用任务开始时间。

时间区间明确限定为「本阶段」。首个批次完成前不估时；有样本后以单批耗时的
指数平滑值（旧值 0.7、新值 0.3）乘剩余串行批次与并发波次数，取 0.65–1.8 倍
作为启发式区间。它不是统计置信区间，也不承诺整个任务的完成时刻。
概念规范化与结构计算还没有稳定样本，因此明确显示时间尚不确定。
超过上界显示等待提示，不停在虚假的「还剩 0 秒」。

每批完成后，最多展示三条过滤后的初步概念及对应知乎原文链接；标题截断到
120 个字符，概念每条最多三个。只允许 HTTPS 的知乎域名，预览保留于该生成
会话内存，不写入分析缓存、不纳入公开分享。会话删除或任务取消后不再发布。

星群命名在生产生成链路中最多四路并发。结果按固定星群次序收集，星群、虫洞
引用和布局保持一致。原 Run API 保留串行兼容行为，RunContext 接受并发安全
的命名器并响应取消。命名缓存读写单独加锁，模型请求期间不持锁。

验证覆盖实际批次计数、时间阶段切换、来源链接校验、预览快照不可变、跨会话
隔离与删除、并发上限、取消排队任务、缓存并发写入，以及并发前后的完整星图
JSON 一致性。全量 Go race、vet、前端相关测试和生产构建通过。浏览器验证了
桌面、手机、矮屏、超时提示及命名阶段切换；截图使用合成进度，未调用真实模型。
