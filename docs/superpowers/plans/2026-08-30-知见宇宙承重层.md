# 知见宇宙：问题行星基础链路 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 mindverse 中完成「真实内容身份 → 私有概念恒星 → 可回链问题行星 → 安全分享视图 → 个人轨道/诚实纪年/棱镜空状态」第一条可运行纵向链路。

**Architecture:** 保留现有个人星群计算，但把内容、用户关系、发现来源和概念作用域拆成不同真相源。第一阶段所有模型抽取的用户概念统一标记为 `private`，直到后续公共概念治理流程能够证明其可公开；绝不猜测来源后提升作用域。只有能解析出真实 `question_id`、非空标题和知乎问题原页 URL 的记录才能生成全局问题行星；完整答案集合投影为全局去重的 `AnswerSatellite`，其余记录只保留为证据。公开搜索结果只有 `DiscoverySource`，绝不生成用户绑定。前端渲染问题行星，并进入三模式工作台；第一阶段的纪年只展示当前存活内容按真实首发时间排列的回溯容器，棱镜无条件明确弃权。分享必须由用户逐项选择公开问题、预览 `ShareView` 后才创建，并由会话所有权索引支持级联删除。

**Tech Stack:** Go 1.25, React 19, TypeScript 6, Three.js/WebGL, Vitest, Testing Library, Vite 8, CSS.

## 不可破坏的契约

- `UserContentBinding` 只允许 `created | collected`；`public_discovered` 只属于 `DiscoverySource`。
- 时间全链路分为 `published_at | updated_at | observed_at`。搜索接口的 `EditTime` 只能映射到 `updated_at`，不得伪造 `published_at` 或收藏时间。
- 问题行星准入条件是：真实 `question_id`、非空标题、规范的 `https://www.zhihu.com/question/{id}`。解析失败不得合成 ID。
- `QuestionPlanet` 按知乎 `question_id` 全局唯一，并以多对多方式被恒星引用。
- 第一阶段所有模型抽取概念（无论来自正文、收藏夹还是个人标签）统一生成 `private` 概念；不得提升为公共 `Concept`，不得自动对外查询。公共概念治理留待后续独立计划。
- `Star.ID = star:v1:{scope}:{sha256(normalized_concept)[:16]}`；标准化固定为 Unicode trim、连续空白折叠、ASCII 小写。相同输入跨重排稳定，不同 scope 不同 ID，碰撞必须显式报错。
- 旧快照只读兼容，不从旧 `Evidence` 合成问题行星。
- `AnswerSatellite` 最少包含稳定内容 ID、真实问题 ID、标题/摘要、原文 URL、`author_id`、作者显示名、三类时间、公开计数、用户绑定和发现来源；按内容 ID 全局去重。只有 URLToken/规范作者主页可生成稳定 `author_id`，只有显示名时作者身份记为 unknown，不能计入独立作者门槛。
- `ShareView` 使用字段白名单；用户必须逐项选择 question ID 并看到准确预览后才能创建，默认不选任何内容。视图移除 `created/collected` 区分、个人时间轨迹、私有概念及绑定；分享元数据持久化 owner session，启动时可重建所有权索引。只有 owner 可删除，其他会话统一返回 404；会话删除时按索引级联删除全部分享副本。
- 当前样本时间线不得称为历史共识。第一阶段不做地层切片：只有至少 12 篇有真实发布时间的独立答案、至少 3 个可验证稳定作者且跨度 3 年，才展示扁平“当前存活答案回溯”；否则只显示原文列表与可见阈值，不展示“答案纪年”。
- 第一阶段没有版本化 `PublicClaim`，棱镜无条件返回 `abstained`，不计算或展示覆盖率/置信度，也不生成填充立场。
