# Babylon 恒星视觉与交互 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Babylon 的点阵恒星和微小几何拾取 with a cinematic three-LOD star layer, stable screen-space interaction, cancellable camera flight, and progressive reveal of question systems.

**Architecture:** Keep `BabylonRenderer` as the orchestration boundary and move deterministic appearance, screen-space hit testing, camera interpolation, and GPU star rendering into focused modules. Render panorama stars in three shared point batches (core/glow/rare flare), reuse one focused sphere/corona pair for the active star, and drive orbit/planet visibility from an explicit presentation progress rather than hard cuts.

**Tech Stack:** TypeScript 6, React 19, Babylon.js 9.23, GLSL ES 3/WebGL2, Vitest 4, Playwright 1.62, Vite 8.

```ts
export interface StarVisualDescriptor {
  color: readonly [number, number, number]
  luminance: number
  panoramaCorePx: number
  panoramaHaloPx: number
  coronaScale: number
  surfaceActivity: number
  seed: number
}

export function describeStarVisual(star: StarDatum): StarVisualDescriptor {
  const bright = clamp(finite(star.bright, 0.5), 0, 2)
  const activity = clamp(finite(star.burst, 0), 0, 1)
  const core = clamp(2 + Math.log1p(bright * 3) * 2.15, 2, 7)
  return Object.freeze({
    color: sanitizeColor(star.color),
    luminance: clamp(0.72 + Math.log1p(bright * 4), 0.72, 2.4),
    panoramaCorePx: core,
    panoramaHaloPx: clamp(core * (2.5 + activity * 1.5), 6, 28),
    coronaScale: 2.5 + activity * 1.5,
    surfaceActivity: activity,
    seed: Math.abs(Math.trunc(finite(star.seed, 1))),
  })
}
```

```ts
export function pickProjectedStar(input: PickInput, candidates: readonly ProjectedStar[]): ProjectedStar | null {
  return candidates
    .filter((candidate) => candidate.visible && insideHit(input, candidate))
    .sort((a, b) => distanceSq(input, a) - distanceSq(input, b)
      || a.depth - b.depth || a.starKey.localeCompare(b.starKey))[0] ?? null
}
```

`PointerGesture` records pointer ID, origin, accumulated Manhattan movement, pressed star key, and cancelled state. It returns `click` only when the released star matches the pressed star and movement is `< 6` CSS px.

## Completion criteria

- The user can distinguish luminous stars in panorama without orbit clutter.
- Hover and click work across the visible halo, not only the physical core.
- Click produces a visible, interruptible camera flight and progressive system reveal.
- Focused stars show procedural surface activity and corona; reduced quality never becomes a black/plain ball.
- Planet and strata behavior remain green.
- Unit tests, lint, Babylon build, targeted E2E, render baselines, and audit pass.
- Only feature files and generated assets intentionally rebuilt for this branch are staged; user snapshot changes remain untouched.
