> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

- [ ] **Step 3: 最小实现稳定 seed 与有界 descriptor**

```ts
export interface PlanetSurfaceDescriptor {
  readonly metadata: Readonly<{ questionId: string; starId: string }>
  readonly seed: number
  readonly radius: number
  readonly craterCount: number
  readonly detailDensity: number
  readonly faultStrength: number
  readonly atmosphere: number
  readonly createdGlow: 0 | 1
  readonly collectedMarker: 0 | 1
  readonly incident: number
  readonly thermal: ThermalWeights
}

export function stablePlanetSeed(questionId: string, starId: string): number {
  let hash = 2166136261
  for (const codePoint of `${questionId}\u0000${starId}`) {
    hash ^= codePoint.codePointAt(0) ?? 0
    hash = Math.imul(hash, 16777619)
  }
  return hash >>> 0
}
```

保留既有公式，但在每个公开输出处调用 `clamp`/`finite`；`createdGlow`、`collectedMarker` 返回字面量 `0 | 1`。

- [ ] **Step 6: 实现纯函数地形预算**

```ts
export type PlanetTerrainLevel = 'low' | 'medium' | 'high'

export interface PlanetCrater {
  readonly direction: readonly [number, number, number]
  readonly radius: number
  readonly depth: number
  readonly rim: number
}

export interface PlanetTerrainDescriptor {
  readonly octaves: 3 | 5 | 6

  readonly ridgeStrength: number

  readonly smallCraterThreshold: number

```

使用本地 xorshift32 PRNG。`largeCraterCount = min(8, max(2, round(craterCount * 0.16)))`，只把这批大坑作为 uniform 传入；`smallCraterBudget = craterCount - largeCraterCount`，转换成 hashed-cell 接受阈值。low 将 `smallCraterBudget` 固定为 0；medium/high 从同一有序大坑序列取前缀，保证 LOD 切换时大型结构不跳变。

- [ ] **Step 3: 实现连续球面地貌**

在 vertex shader 中加入无 UV 的三维 gradient noise：

```glsl
float terrainHeight(vec3 direction) {
  vec3 warped = direction + domainWarp(direction * 1.7) * uWarpStrength;
  float continents = fbm(warped * 2.1, uOctaves);
  float mountainMask = smoothstep(0.48, 0.72, continents);
  float ridges = ridgedNoise(warped * 5.4, uOctaves) * mountainMask * uFaultStrength;
  float fineDetail = detailNoise(warped * mix(11.0, 23.0, uDetailDensity))
    * mix(0.0, 0.08, uDetailDensity);
  return (continents - 0.48) * 0.72 + ridges * 0.28
    + fineDetail + largeCraterField(direction) + smallCraterField(direction);
}
```

WebGL2 中用固定上限循环与 `if (i >= uOctaves) break`。大坑 uniform 数组固定上限为 8，未使用项半径设为零。小坑不遍历 uniform，也不做 cube-face 投影：在 `direction * frequency` 的连续三维空间中取当前整数 cell，检查固定的 `3×3×3` 邻域；每个 cell hash 产生候选点和接受值，候选点归一化回球面后用 chord distance 与同一个 `craterProfile` 计算碗底/坑壁/抬升环。medium 只计算一个尺度，high 计算两个尺度，low 不计算；预算只改变 `uSmallCraterThreshold`。三维方向域跨经纬和 cube face 连续，因此不存在 UV 或 face 接缝。

- [ ] **Step 4: 实现球面切向有限差分法线**

```glsl
vec3 displacedNormal(vec3 radial) {
  vec3 tangent = normalize(abs(radial.y) < 0.95
    ? cross(radial, vec3(0.0, 1.0, 0.0))
    : cross(radial, vec3(1.0, 0.0, 0.0)));
  vec3 bitangent = normalize(cross(radial, tangent));
  float epsilon = uNormalEpsilon;
  vec3 a = normalize(radial + tangent * epsilon);
  vec3 b = normalize(radial - tangent * epsilon);
  vec3 c = normalize(radial + bitangent * epsilon);
  vec3 d = normalize(radial - bitangent * epsilon);
  vec3 dpT = a * (1.0 + terrainHeight(a) * uDisplacement)
    - b * (1.0 + terrainHeight(b) * uDisplacement);
  vec3 dpB = c * (1.0 + terrainHeight(c) * uDisplacement)
    - d * (1.0 + terrainHeight(d) * uDisplacement);
  return normalize(cross(dpT, dpB));
}
```

确认 Babylon 坐标系下法线朝外；若测试样片显示反向，只在 cross 顺序处修正，不在 fragment 中 `abs` 掩盖。

- [ ] **Step 3: 实现空间材质分区与简化 dielectric GGX**

vertex 明确输出归一化径向 `vRadial`、有符号高度 `vHeight`、ridge/crater masks 和位移后法线。fragment 先计算空间分区：

```glsl
float latitude = abs(vRadial.y);
float polarMask = smoothstep(mix(0.82, 0.48, uThermalIce), 0.98, latitude);
float highlandMask = smoothstep(0.10, 0.42, vHeight);
float basinMask = 1.0 - smoothstep(-0.30, 0.08, vHeight);
float hotZone = uThermal.x * (1.0 - polarMask) * smoothstep(-0.08, 0.24, vHeight);
float iceZone = max(uThermalIce * polarMask, uThermal.w * polarMask * 0.55);
float desertZone = uThermal.y * (1.0 - polarMask)
  * (1.0 - highlandMask * 0.45) * (0.65 + basinMask * 0.35);
float exposedRock = clamp(uThermal.z + highlandMask * 0.55
  + basinMask * 0.25 + craterMask * 0.35, 0.0, 1.0);
```

这些 mask 经过归一化后混合各自 baseColor 和 roughness，确保同一颗行星同时存在极区、低地和高地，而非全局纯色。`uDetailDensity` 同时控制 Task 2 中高频 detail 的频率与幅度，但不改变大陆和大型 crater。

随后在线性空间计算 `N/L/V/H`、Lambert diffuse、GGX NDF、height-correlated Smith visibility 和 Schlick Fresnel。金属度固定为 0；岩石、沙、冰、熔岩分别使用不同 roughness。普通地表最终 HDR 分量限制在 Bloom threshold 以下，只有由 ridge/crater 裂隙 mask 约束的熔岩与 `createdGlow` 可超过 1。

```ts
function projectedCoverage(
  radius: number,
  cameraDistance: number,
  verticalFov: number,
  renderWidth: number,
  renderHeight: number,
): number {
  if (![radius, cameraDistance, verticalFov, renderWidth, renderHeight].every(Number.isFinite)
    || radius <= 0 || cameraDistance <= radius || renderWidth <= 0 || renderHeight <= 0) return 0
  const angularRadius = Math.asin(Math.min(1, radius / cameraDistance))
  const diameterPixels = 2 * Math.tan(angularRadius) * renderHeight / (2 * Math.tan(verticalFov * 0.5))
  return Math.min(1, Math.max(0, diameterPixels / Math.min(renderWidth, renderHeight)))
}
```

该值严格表示投影直径占画布短边比例，并在竖屏时考虑宽度限制。每帧仅更新可见行星；`selectedVisual` 传入 `focused=true`，其他对象禁止 high。相机 anchor 与拾取统一解析 `PlanetVisual.activeMesh`。
